# Country-API
In this project, a city's information can be found such as its religion, language or population. I was able to do this using an API to get information of the demographics of a city entered by the user.
I used Tkinter to create a user interface of this program and added features such as the background color, title and the size of the window. Using this program, the user can easily have a brief understanding of the
city they wish to search. I created a new function where I accessed the API through JSON viewer.
